# 物品套装

## 描述

这是一个为AzerothCore开发的物品套装模块，允许玩家通过收集和装备特定的物品组合来获得额外的属性加成和特殊效果。

## 功能

- 定义套装组合（多件物品组成一套）
- 套装效果等级（穿戴不同数量的套装物品获得不同等级的效果）
- 套装属性加成（基础属性、特殊属性）
- 套装特殊效果（技能、光环、外观等）
- 套装管理界面（查看已收集套装、效果预览）

## 安装

1. 将此模块放入 `modules` 目录
2. 重新运行 CMake
3. 重新编译 AzerothCore
4. 导入SQL文件到相应数据库：
   - `sql/world/_模板_物品套装.sql` 到 world 数据库

## 配置

配置文件位于 `conf/mod_item_sets.conf.dist`，可以根据需要进行调整。

## 命令

### 管理员命令
- `.套装 列表` - 列出所有可用的套装
- `.套装 信息 [套装ID]` - 显示指定套装的详细信息
- `.套装 玩家 [玩家名称]` - 显示指定玩家的套装收集情况
- `.套装 重载` - 重新加载套装数据

### 玩家命令
- `.物品套装 创建 [套装ID] [物品ID1,物品ID2,...]` - 创建套装并指定包含的物品
- `.物品套装 取消 [套装ID]` - 取消激活指定的套装
- `.物品套装 检查` - 检查当前装备中的套装物品
- `.物品套装 刷新` - 刷新套装效果

## 使用方法

### 基本流程
1. 在游戏中收集套装物品
2. 使用 `.物品套装 创建 [套装ID] [物品ID1,物品ID2,...]` 创建套装映射
3. 装备套装物品
4. 系统会自动检测装备变化并更新套装效果

### 套装创建示例
```
.物品套装 创建 1 12345,12346,12347,12348,12349,12350
```
这将创建套装ID为1的套装，包含物品12345到12350

### 自动检测功能
- 装备套装物品时会自动更新套装效果
- 装备/卸下物品时会自动重新计算套装件数
- 套装件数变化时会显示相应提示
- 支持多属性套装效果组合

### 客户端插件
- 将 `客户端ui插件` 文件夹复制到WoW客户端的 `Interface\AddOns\` 目录
- 重启游戏或重新加载插件
- 使用 `/套装` 或 `/itemsets` 命令打开套装界面
- 小地图上会显示物品套装按钮

## 数据库结构

### 物品套装表 (_模板_物品套装)

```sql
CREATE TABLE IF NOT EXISTS `_模板_物品套装` (
  `套装ID` int(10) unsigned NOT NULL COMMENT '套装唯一标识',
  `组` int(10) unsigned NOT NULL DEFAULT 0 COMMENT '套装组别，用于分类管理',
  `套装名称` varchar(255) NOT NULL COMMENT '套装的名称',
  `套装描述` text DEFAULT NULL COMMENT '套装的详细描述',
  `需求系统ID` int(10) unsigned DEFAULT 0 COMMENT '需求系统模板ID',
  `套装品质` tinyint(3) unsigned DEFAULT 0 COMMENT '套装的品质等级',
  `物品数量` tinyint(3) unsigned DEFAULT 0 COMMENT '激活效果需要的物品数量',
  `效果类型` tinyint(3) unsigned DEFAULT 0 COMMENT '效果类型(1=属性,2=技能,3=光环)',
  `套装属性` text DEFAULT NULL COMMENT '套装属性效果，格式: "属性类型 数值,属性类型 数值"',
  `效果ID` int(10) unsigned DEFAULT 0 COMMENT '效果ID(技能ID/光环ID)',
  `效果数值` float DEFAULT 0 COMMENT '效果的数值大小',
  `效果描述` varchar(255) DEFAULT NULL COMMENT '效果的文字描述',
  PRIMARY KEY (`套装ID`, `物品数量`),
  KEY `套装ID` (`套装ID`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物品套装基本信息表';
```

### 套装物品映射表 (套装物品映射)

```sql
CREATE TABLE IF NOT EXISTS `套装物品映射` (
  `套装ID` int(10) unsigned NOT NULL COMMENT '套装ID',
  `物品ID` int(10) unsigned NOT NULL COMMENT '物品模板ID',
  `物品名称` varchar(255) DEFAULT NULL COMMENT '物品名称',
  `装备槽位` tinyint(3) unsigned DEFAULT 0 COMMENT '装备槽位类型',
  `是否启用` tinyint(1) unsigned DEFAULT 1 COMMENT '是否启用该物品',
  PRIMARY KEY (`套装ID`, `物品ID`),
  KEY `物品ID` (`物品ID`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='套装物品映射关系表';
```
