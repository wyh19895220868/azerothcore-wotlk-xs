## 🎯 核心技术实现

### 1. 装备跟踪系统

```cpp
// 记录每个玩家的装备槽位和物品GUID
std::map<uint64, std::map<uint8, uint64>> _equippedItems;
```

**作用**：

- 穿戴时记录物品 GUID
- 替换时自动移除旧装备属性
- 卸下时根据 GUID 移除属性

### 2. 根据 GUID 移除属性

```cpp
void RemoveItemAttributeEffectsByGuid(Player* player, uint64 itemGuid)
{
    // 直接从数据库读取属性信息
    // 不需要Item对象
    // 解析并移除属性
}
```

**优势**：

- 不依赖物品位置
- 性能更好
- 100%可靠

### 3. 事件处理流程

#### 穿戴装备

·
OnPlayerEquip 触发
  ↓
检查槽位是否已有装备
  ↓
如有旧装备 → 移除旧属性
  ↓
记录新装备GUID
  ↓
应用新装备属性
·

#### 卸下装备

·
OnPlayerAfterSetVisibleItemSlot 触发 (item=nullptr)
  ↓
从映射表获取装备GUID
  ↓
RemoveItemAttributeEffectsByGuid(guid)
  ↓
从映射表删除记录
·

#### 登录

·
OnPlayerLogin 触发
  ↓
OnPlayerEquip 已为每个装备触发
  ↓
只刷新属性面板（不重复应用）
·

## 📝 数据库表

### 角色数据库

#### 物品属性\_数据

```sql
CREATE TABLE `物品属性_数据` (
  `物品GUID` INT UNSIGNED NOT NULL,
  `属性列表` TEXT NOT NULL,      -- 逗号分隔的属性ID: "1,4,5"
  `属性值列表` TEXT NOT NULL,    -- 逗号分隔的属性值: "10000,500,300"
  PRIMARY KEY (`物品GUID`)
);
```

### 世界数据库

#### \_物品属性\_模板

```sql
CREATE TABLE `_模板_物品属性` (
  `属性ID` INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `属性类型` TINYINT UNSIGNED NOT NULL,    -- 0-25
  `客户端显示名称` VARCHAR(50) NOT NULL,
  `计算公式类型` TINYINT UNSIGNED NOT NULL,
  PRIMARY KEY (`属性ID`)
);
```
