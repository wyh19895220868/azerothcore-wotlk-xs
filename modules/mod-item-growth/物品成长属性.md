# 成长属性显示问题修复说明

## 问题描述
成长属性只有装备所有者自己能看到，其他玩家从聊天框链接、观察装备等场景无法看到成长属性。

## 根本原因
客户端插件在 `SetInventoryItem` 钩子中只检查 `unit == "player"`，导致查看其他玩家装备时不会触发成长属性查询。

## 修复方案

### 1. 客户端修复（已完成）
**文件**: `modules\mod-item-growth\客户端ui插件\ItemGrowthTooltip\ItemGrowthTooltip.lua`

**修改位置**: 第630-638行

**修改内容**:
```lua
-- 修改前（只处理player）
hooksecurefunc(GameTooltip, "SetInventoryItem", function(self, unit, slot)
    if unit == "player" then
        local itemLink = GetInventoryItemLink(unit, slot)
        local itemID, itemGUID, rpId = GetItemInfo(itemLink, nil, slot)
        AddGrowthInfoToTooltip(self, itemLink, itemID, itemGUID, rpId, nil, slot, true)
    end
end)

-- 修改后（处理所有单位）
hooksecurefunc(GameTooltip, "SetInventoryItem", function(self, unit, slot)
    -- 关键修复：移除 unit == "player" 限制，支持查看任何单位的装备
    -- 这样可以在观察其他玩家装备时也显示成长属性
    local itemLink = GetInventoryItemLink(unit, slot)
    if itemLink then
        local itemID, itemGUID, rpId = GetItemInfo(itemLink, nil, slot)
        AddGrowthInfoToTooltip(self, itemLink, itemID, itemGUID, rpId, nil, slot, true)
    end
end)
```

### 2. 服务器端机制（已完整实现，无需修改）

服务器端已经实现了完整的跨玩家查询机制：

#### GUID存储机制
- 使用 `GUID + GROWTH_GUID_OFFSET` 存储到 `randomPropertyId` 字段
- 使用 `GUID` 存储到 `ITEM_FIELD_PROPERTY_SEED` 字段
- 常量 `GROWTH_GUID_OFFSET = 1000000` 避免与DBC随机属性冲突

**实现位置**: `ItemGrowthCore.cpp` 第50-112行 (`EnsureItemUniqueSeed` 函数)

#### 查询处理机制
`.物品成长 查询` 命令支持以下查询场景：

1. **查询自己的装备**
   - 通过GUID在自己的背包/装备栏查找

2. **查询同地图其他玩家的装备**
   - 通过 `FindNearbyItemBySeed` 函数在同地图玩家中搜索
   - 使用seed（从装备链接的uniqueId字段）匹配物品

3. **查询聊天链接中的装备**
   - 如果找不到物品实例，直接从数据库查询成长记录
   - 返回成长信息给客户端

**实现位置**: `ItemGrowthCommands.cpp` 第2579-2826行 (`HandleItemGrowthQueryCommand` 函数)

#### 辅助查找函数
- `FindPlayerItemByIdAndGuid`: 按物品ID和GUID查找
- `FindPlayerItemBySeed`: 按seed查找（支持位置参数）
- `FindPlayerItemByPosition`: 按背包位置查找
- `FindNearbyItemBySeed`: 在同地图所有玩家中按seed查找

### 3. 工作流程

#### 自己查看自己的装备
1. 玩家装备物品时，`EnsureItemUniqueSeed` 设置seed和randomPropertyId
2. 鼠标悬停时，客户端从装备链接提取GUID
3. 客户端发送查询命令（WHISPER给自己）
4. 服务器在玩家背包/装备栏中找到物品
5. 返回成长信息显示在Tooltip

#### 其他玩家查看装备
1. 玩家A在聊天框发送装备链接或被玩家B观察装备
2. 玩家B的客户端从装备链接提取GUID
3. 玩家B的客户端发送查询命令
4. 服务器尝试在玩家B的背包中查找（失败）
5. 服务器在同地图其他玩家中查找（如果玩家A在同地图）
6. 或直接从数据库查询成长记录
7. 返回成长信息显示在玩家B的Tooltip

## 参考实现
本修复参考了强化系统（mod-item-enhancement）的实现方式：
- 使用randomPropertyId字段存储GUID
- 支持跨玩家查询装备信息
- 使用数据库查询作为明确的数据来源

## 注意事项
1. 客户端插件使用60秒查询间隔限制，避免频繁查询
2. 查询使用WHISPER发送给自己，不会在聊天框显示
3. GUID偏移量确保不与DBC中的随机属性ID冲突
4. 支持新旧格式兼容（旧格式直接存储GUID，新格式使用偏移量）
