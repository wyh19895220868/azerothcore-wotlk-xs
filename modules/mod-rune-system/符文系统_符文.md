# 符文系统模块

## 描述

符文系统是一个为AzerothCore设计的模块，允许玩家为武器和装备添加符文，以增强其属性和效果。符文可以提供各种增益效果，如增加属性、触发法术或提供特殊能力。

## 功能

### 核心功能

- 为物品添加符文插槽
- 解锁符文插槽
- 添加符文到物品
- 升级符文
- 移除符文
- 转移符文
- 符文效果系统

## 安装

### 模块安装

1. 将此模块复制到AzerothCore源代码的`modules`目录中。
2. 重新运行CMake。
3. 重新编译AzerothCore。

### 数据库安装

在服务器启动之前，需要应用SQL文件：

1. 将`sql/world`目录中的SQL文件应用到您的世界数据库。
2. 将`sql/characters`目录中的SQL文件应用到您的角色数据库。
3. 将`sql/auth`目录中的SQL文件应用到您的认证数据库。

## 配置

配置选项可以在`RuneSystem.conf.dist`文件中找到。您可以根据需要调整这些设置。

## 命令

### 玩家命令

- `.rune info [物品ID]` - 显示物品的符文信息

### GM命令

- `.rune add <物品ID> <插槽ID> <符文ID>` - 添加符文到物品
- `.rune remove <物品ID> <插槽ID>` - 从物品移除符文
- `.rune upgrade <物品ID> <插槽ID>` - 升级符文
- `.rune slot <物品ID> [数量]` - 添加符文插槽到物品
- `.rune unlock <物品ID> <插槽ID>` - 解锁符文插槽
- `.rune list [槽位] [品质]` - 列出符文

### 管理员命令

- `.rune create <名称>,<槽位(1-20)>,<品质>,<法术ID>,<冷却时间>,<触发几率>,<效果类型>` - 创建新符文
- `.rune delete <符文ID>` - 删除符文

## 符文槽位

- 槽位 1-20：表示符文可以装备在第几个槽位，每个符文只能装备在其指定的槽位

## 符文品质

- 0 = 普通
- 1 = 优秀
- 2 = 精良
- 3 = 史诗
- 4 = 传说

## 效果类型

- 0 = 无加成 (效果值: 空字符串)
- 1 = 属性加成 (效果值: `属性ID 数值,属性ID 数值`, 如: `3 10,4 15`)
- 2 = 技能加成 (效果值: `99 数值`, 如: `99 20`, 根据技能类型动态加成)
- 3 = 百分比属性加成 (效果值: `属性ID 百分比`, 如: `3 5`)
- 4 = 百分比技能加成 (效果值: `99 百分比`, 如: `99 10`)

### 效果值格式说明

**属性加成**: `属性ID 数值,属性ID 数值`

- `4 5` = 力量+5
- `3 10,4 15` = 耐力+10, 力量+15

**技能加成**: `99 数值`

- `99 20` = 技能+20 (伤害技能增加伤害, 治疗技能增加治疗量)
- 99 为固定标识符，系统自动根据法术ID判断技能类型

## 示例

1. 为物品添加符文插槽：

   ```bash
   .rune slot 12345 3
   ```

2. 解锁符文插槽：

   ```bash
   .rune unlock 12345 1
   ```

3. 添加符文到物品：

   ```bash
   .rune add 12345 1 5
   ```

4. 升级符文：

   ```bash
   .rune upgrade 12345 1
   ```

5. 移除符文：

   ```bash
   .rune remove 12345 1
   ```

## 注意事项

- 符文只能添加到武器和装备上。
- 符文插槽必须先解锁才能添加符文。
- 符文等级不能超过符文的最大等级。
- 玩家等级必须达到符文的需求等级才能使用该符文。

## 技术说明

- 此模块使用现代C++格式化符 `{}` 而非旧式的 `{}`, `{}` 等。
- 模块已更新以兼容最新版本的AzerothCore。
- 符文效果通过修改玩家属性和触发法术来实现。
