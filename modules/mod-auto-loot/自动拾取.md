# 自动拾取模块

## 描述

该模块为AzerothCore添加了自动拾取功能。当玩家击杀生物后，战利品会自动添加到玩家的背包中，无需手动拾取尸体。

## 功能

- 自动拾取击杀生物掉落的物品
- 自动拾取金币
- 支持团队/小队拾取规则
- 当背包已满时，物品会通过邮件发送给玩家

## 安装

### 源码安装

1. 将模块复制到AzerothCore源码的`modules`目录中
2. 重新运行cmake和编译AzerothCore

## 配置

### 服务器配置选项

这些选项必须添加到您的`worldserver.conf`文件中。
如果它们不存在，则将使用默认值。

#### AutoLoot.Enable
* 类型: 布尔值 (0 或 1)
* 默认值: 1 (启用)

启用或禁用自动拾取功能。

#### AutoLoot.Money
* 类型: 布尔值 (0 或 1)
* 默认值: 1 (启用)

启用或禁用自动拾取金币。

#### AutoLoot.QuestItems
* 类型: 布尔值 (0 或 1)
* 默认值: 1 (启用)

启用或禁用自动拾取任务物品。

#### AutoLoot.Debug
* 类型: 布尔值 (0 或 1)
* 默认值: 0 (禁用)

启用或禁用调试日志。

## 注意事项

- 此模块尊重团队/小队拾取规则。在使用需要手动分配的拾取模式（如队长分配、队伍分配、需求优先）时，物品不会自动拾取。
- 当玩家背包已满时，物品会通过邮件发送给玩家。
- 对于唯一物品，如果玩家已经拥有该物品，模块会跳过拾取并标记为已拾取，不会通过邮件发送。
- 对于有数量限制的物品，如果玩家已达到最大数量限制，模块会跳过拾取并标记为已拾取，不会通过邮件发送。
