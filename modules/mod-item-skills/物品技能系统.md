## 📋 项目概述

物品技能系统是一个完整的模块，参考物品属性系统实现，为装备添加技能效果。实现了装备触发技能、击中触发技能、使用触发技能等多种触发方式，相当于官方的套装效果系统。

### 2. 数据库结构

#### 角色数据库表 (`_物品技能_数据`)

```sql
- 物品ID: 物品Entry ID
- 物品GUID: 物品唯一标识符
- 技能列表: 技能模板ID列表（逗号分隔）
- 技能等级列表: 技能等级列表（逗号分隔）
- 技能使用次数列表: 剩余使用次数列表
- 上次触发时间列表: 技能触发时间戳列表
```

#### 世界数据库表 (`_模板_物品技能`)

```sql
- id: 技能模板唯一ID
- 物品id: 关联的物品ID
- 注释: 技能描述（管理用）
- 客户端显示: 显示给玩家的描述
- 组: 技能组ID（用于升级）
- 等级: 技能等级
- 限制条件: 物品类别、等级等限制
- 技能id: 实际的技能ID
- 几率: 随机获得的权重
- 技能触发类型: 0=使用 1=装备 2=击中 100=学习
- 技能使用次数: 使用次数限制
- 技能每分钟触发次数: PPM触发率
- 技能冷却时间: 冷却时间（毫秒）
- 启用状态: 是否启用
- 优先级: 技能优先级
```

## 🎯 技能触发类型详解

### 1. 使用触发 (ITEM_SKILL_TRIGGER_ON_USE = 0)

- **说明**: 玩家主动使用物品时触发
- **示例**: 使用药水释放火球术
- **特点**: 可控制使用次数和冷却时间

### 2. 装备触发 (ITEM_SKILL_TRIGGER_ON_EQUIP = 1)

- **说明**: 装备物品时立即施放技能
- **示例**: 装备武器时获得增益光环
- **特点**: 卸下装备时自动移除效果

### 3. 击中触发 (ITEM_SKILL_TRIGGER_ON_HIT = 2)

- **说明**: 攻击命中敌人时有几率触发
- **示例**: 攻击时触发闪电链
- **特点**: 支持PPM（每分钟触发次数）控制

### 4. 学习技能 (ITEM_SKILL_TRIGGER_LEARN_SPELL = 100)

- **说明**: 装备时学习技能，卸下时遗忘
- **示例**: 装备后学会特殊技能
- **特点**: 技能添加到技能书

## 📊 数据流程

### 装备穿戴流程

·
玩家装备物品
    ↓
OnEquip 事件触发
    ↓
检查槽位是否有旧装备
    ↓
如有旧装备 → 移除旧技能效果（通过GUID）
    ↓
记录新装备GUID
    ↓
从数据库读取技能数据
    ↓
应用技能效果（根据触发类型）
·

### 装备卸下流程

·
玩家卸下装备
    ↓
OnAfterSetVisibleItemSlot 事件触发（item=nullptr）
    ↓
从装备跟踪表获取物品GUID
    ↓
从数据库读取技能数据
    ↓
移除技能效果
    ↓
从装备跟踪表删除记录
·

### 击中触发流程

·
玩家造成伤害
    ↓
OnDealDamage 事件触发
    ↓
遍历所有装备槽位
    ↓
检查每个装备的击中触发技能
    ↓
PPM几率检查
    ↓
冷却时间检查
    ↓
触发技能
    ↓
更新触发时间和使用次数
·

## 🚀 安装和配置

### 1. 数据库安装

```bash
# 导入世界数据库表
mysql -u root -p acore_world < sql/world/_模板_物品技能.sql

# 导入角色数据库表
mysql -u root -p acore_characters < sql/characters/_物品技能_数据.sql
```

### 2. 编译模块

模块已集成到CMakeLists.txt，重新编译服务器即可。

### 3. 配置文件

编辑 `conf/mod_item_skills.conf`:

```ini
ItemSkills.Enable = 1
ItemSkills.AllowPlayerCommands = 1
ItemSkills.ChanceModifier = 1.0
ItemSkills.CooldownModifier = 1.0
ItemSkills.PPMModifier = 1.0
```

### 4. 客户端插件安装

将 `客户端ui插件/ItemSkillsTooltip` 文件夹复制到客户端的 `Interface/AddOns/` 目录。

## 🎨 技能效果实现原理

### 装备触发技能

```cpp
// 装备时立即施放技能
player->CastSpell(player, skillTemplate->spellId, true);

// 卸下时移除光环效果
player->RemoveAurasDueToSpell(skillTemplate->spellId);
```

### 击中触发技能

```cpp
// 检查PPM几率
float chance = skillTemplate->ppmRate / 60.0f;
if (frand(0.0f, 1.0f) > chance)
    return;

// 检查冷却
if (!CheckSkillCooldown(player, item, skillTemplate))
    return;

// 触发技能
player->CastSpell(victim, skillTemplate->spellId, true);
```

### 技能强化效果

可以通过击中触发实现类似套装效果的技能强化：

- 攻击时增加技能伤害
- 施法时减少技能消耗
- 特定技能触发额外效果

## ⚠️ 注意事项

1. **技能ID**: 确保使用的技能ID在 spell.dbc 中存在
2. **冷却时间**: 单位为毫秒，-1表示使用技能默认冷却
3. **使用次数**: 0=无限，正数=用完不删除，负数=用完删除物品
4. **PPM**: 仅对击中触发有效，控制每分钟触发次数
5. **GUID管理**: 系统自动管理物品GUID，确保技能正确应用和移除
