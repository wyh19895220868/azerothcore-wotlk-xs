# 物品鉴定系统

## 简介

物品鉴定系统是一个为AzerothCore开发的模块，允许玩家对未鉴定的物品进行鉴定，随机获得各种属性加成、技能和特殊效果。

## 功能

- 物品鉴定：玩家可以对武器和护甲进行鉴定，获得随机属性
- 随机属性系统：基于数据库配置的属性模板，为物品添加随机属性
- 物品名称和描述自定义：可以为鉴定后的物品添加前缀、后缀和自定义描述
- 物品颜色自定义：可以为鉴定后的物品名称设置自定义颜色
- 符文系统：为物品添加符文凹槽
- 公告系统：当玩家鉴定出高品质物品时，向全服发送公告

## 安装

1. 将模块放入 `modules` 目录
2. 重新运行 cmake 和编译过程
3. 导入SQL文件到world数据库：`modules/mod-item-identification-system/data/sql/db-world/_模板_物品鉴定.sql`
4. 在 world 数据库执行 `data/sql/updates/pending_db_world/rev_1792891614895422300.sql`，再启动新版本。
5. 完成！

## 配置

配置文件位于 `modules/mod-item-identification-system/conf/ItemIdentificationSystem.conf.dist`

主要配置选项：

- `ItemIdentificationSystem.Enable`：启用/禁用模块
- `ItemIdentificationSystem.BaseSuccessRate`：鉴定基础成功率
- `ItemIdentificationSystem.DestroyOnFail`：鉴定失败是否销毁物品
- `ItemIdentificationSystem.Cost`：鉴定所需金币
- `ItemIdentificationSystem.EnableAnnounce`：是否启用公告系统
- `ItemIdentificationSystem.Debug`：调试模式

## 使用方法

玩家可以使用以下命令鉴定物品：

- `.identify item [槽位]`：鉴定指定槽位的物品
- 或者将物品放入交易窗口，然后使用 `.identify item` 命令

## 数据库结构

模块使用 `_模板_物品鉴定` 表来存储鉴定模板数据。表结构包括：

- `id`：模板ID
- `组`：模板组ID
- `等级`：适用的物品等级
- `随机几率`：模板被选中的几率
- `物品名字前缀`：鉴定后添加的前缀
- `物品名字后缀`：鉴定后添加的后缀
- `物品名字颜色_多个逗号隔开`：物品名称的颜色代码
- `物品底部描述`：添加到物品描述的文本
- 以及其他属性相关字段

## 模板附魔配置

模板鉴定和模板附魔洗炼使用 `_模板_物品附魔`，通过 `_模板_物品鉴定.随机附魔组` 关联 `组号`。
每行配置 `组号`、`附魔编号`、`生效几率` 和 `备注`，同组同附魔编号不能重复。
`生效几率` 表示进入随机候选池的概率，附魔编号来自 SpellItemEnchantment。

上述迁移在新表不存在时复制 `_装备超级随机附魔组表` 的配置；如果旧表也不存在，则创建空表。
新表已经存在时不追加或覆盖数据。迁移不修改旧表，新代码只读取新表；后续请在新表维护附魔配置。
旧装备超级随机系统及官方附魔洗炼仍使用各自的配置表，本次不改变它们。
