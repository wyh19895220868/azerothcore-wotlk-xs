# 生物自定义掉落

本模块读取 World 库中的 `_生物自定义掉落表`，支持生物、物品和游戏物体作为掉落来源。该表由 `20261018_00_naz_custom_world.sql` 创建。

字段取值：`类型` 为 `生物`、`物品` 或 `物体`；`允许多倍` 为 `关闭` 或 `开启`。

```sql
INSERT INTO `_生物自定义掉落表`
(`类型`, `来源编号`, `物品编号`, `几率`, `最小数量`, `最大数量`, `允许多倍`)
VALUES
('生物', 12345, 60000, 10, 1, 3, '开启'),
('物品', 70000, 60001, 100, 5, 10, '关闭'),
('物体', 180001, 60002, 25, 1, 1, '关闭');
```

修改数据后可执行 `.reload customloot` 或 `.自定义掉落 重载`。

每条命中的配置只占一个掉落格；拾取后按物品自身的堆叠数量放入背包。超出拾取窗口或背包容量的物品会通过邮件补发。
