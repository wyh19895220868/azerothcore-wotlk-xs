# 物品强化系统

## 描述

物品强化系统是一个为AzerothCore开发的模块，允许玩家强化他们的装备，提升装备属性和能力。该系统包含多种功能，包括基础强化、套装强化、专精强化、突破强化、共鸣系统和元素系统。

## 功能

### 基础强化

- 允许玩家强化装备，提升基础属性
- 强化等级越高，成功率越低
- 强化失败可能导致等级降低或物品摧毁（可通过配置保护）
- 强化成功时可获得额外属性和技能

### 套装强化

- 同一套装的多件物品强化到特定等级后激活套装效果
- 套装效果可提供额外属性加成和特殊能力
- 支持多种套装组合和效果

### 专精强化

- 为物品选择特定的强化方向（攻击、防御、生命、法术等）
- 不同专精提供不同类型的属性加成
- 专精等级提升可解锁特殊技能
- 通过专精ID可以灵活定义不同的专精类型和效果

### 突破强化

- 当物品达到最大强化等级后，可以进行突破
- 突破后可以继续提升强化等级上限
- 突破成功后获得显著的属性提升和特殊视觉效果
- 通过突破ID可以定义不同的突破路径和效果

### 共鸣系统

- 当玩家同时装备多件属于同一共鸣组的物品时，触发共鸣效果
- 共鸣效果提供额外的属性加成和特殊能力
- 支持多种共鸣组合和效果
- 通过共鸣ID可以定义不同的共鸣类型和触发条件

### 元素系统

- 物品可以附加不同的元素属性（火、水、风、土、光、暗）
- 不同元素之间有相生相克关系
- 元素属性提供额外的伤害、抗性和特殊效果
- 通过元素ID可以定义不同的元素类型和特殊效果

## 安装

1. 将模块复制到 `modules` 目录
2. 重新运行 CMake
3. 重新编译服务器
4. 导入SQL文件到相应数据库：
   - `sql/world/_模板_物品强化.sql` 到 world 数据库
   - `sql/characters/物品强化_记录.sql` 到 characters 数据库

## 配置

配置文件位于 `configs/modules/ItemEnhancement.conf.dist`，可以根据需要调整以下参数：

- 启用/禁用各个功能模块
- 调整强化成功率、消耗和属性加成系数
- 设置强化最大等级和突破次数
- 配置公告和调试选项

## 命令

- `.强化 帮助` - 显示帮助信息
- `.强化 强化 [装备栏位]` - 强化指定栏位的装备
- `.强化 专精 [装备栏位] [专精类型]` - 为指定栏位的装备设置专精
- `.强化 升级专精 [装备栏位]` - 提升指定栏位装备的专精等级
- `.强化 突破 [装备栏位]` - 突破指定栏位装备的等级上限
- `.强化 元素 [装备栏位] [元素类型]` - 为指定栏位的装备附加元素
- `.强化 升级元素 [装备栏位]` - 提升指定栏位装备的元素等级
- `.强化 信息 [装备栏位]` - 查看指定栏位装备的强化信息
- `.强化 重载` - 重新加载物品强化系统配置和数据（GM命令）

## 数据库结构

### _模板_物品强化

包含强化模板数据，定义了不同强化等级的属性、成功率和效果。主要字段包括：

- `id`：模板唯一标识符
- `组`：强化组ID，用于分类不同类型的强化
- `等级`：强化等级
- `几率`：强化成功率
- `专精id`：专精的唯一标识符，用于定义不同的专精类型
- `专精类型`：专精的类型（攻击、防御、生命、法术等）
- `突破id`：突破的唯一标识符，用于定义不同的突破路径
- `共鸣id`：共鸣的唯一标识符，用于定义不同的共鸣效果
- `共鸣组ID`：共鸣组ID，用于识别可以产生共鸣效果的物品组
- `元素id`：元素的唯一标识符，用于定义不同的元素类型
- `元素类型`：元素的类型（火、水、风、土、光、暗）

### 物品强化_记录

记录玩家物品的强化状态，包括强化等级、专精类型、突破次数和元素类型等。
